# 法医昆虫学鉴定结论复核沙盘

一个矛盾驱动的法医昆虫学鉴定结论复核训练工具。内置多组案件材料，使用者选择假设后，
将每份证据标为「支持 / 反驳 / 待核实」，系统持续提示时间矛盾、生态不可能与证据链断点；
可切换假设、回退步骤、合并冲突，未处理冲突或缺少依据时无法锁定结论；锁定后生成可导出的
复核摘要。桌面四栏、窄屏底部四步标签页，均可走完整条复核流程。

## 内置案件

1. **城南公寓腐尸案** —— 室内高温使发育历期与手机最后活动记录矛盾；鉴定资质缺陷。
2. **西郊山林弃尸案** —— 高海拔林缘出现城区暖热蝇种（生态不可能），虫龄大于现场停留时长，指向移尸。
3. **北岸冬季车库案** —— 间歇供暖微气候下分段积温重算，虫群定殖早于死者进入现场（时间倒挂）。

每组案件含：物种鉴定、发育阶段、死亡时间、保存与污染、来源可信度五类材料，
3 个待复核假设，以及 6 条即时规则检查点。

## 复核流程

1. **选假设**：每个假设独立保存标注与冲突处置，可随时切换。
2. **标材料**：支持 / 反驳 / 待核实三态，可按材料类别筛选。
3. **处冲突**：系统对标注组合即时给出阻断（矛盾/不可能/断点）与注意提示；
   通过「合并证据组」或「解释保留」写入实质性说明后解除阻断；处置可撤销，操作可逐步回退。
4. **锁结论**：门禁检查——无未处置阻断矛盾、假设所需依据类别齐备（低可信孤证不计；
   主动反驳的类别须全部标注并处置）、材料全部三态标注、复核说明已填写。
   锁定后生成 Markdown 复核摘要，可复制或下载 `.md`；解锁后可继续编辑。

## 技术栈与运行

React 19 + Vite + TypeScript，无额外运行时依赖。

```bash
npm install
npm run dev      # http://localhost:62003
npm run build    # 类型检查 + 生产构建
```

规则引擎位于 `src/engine.ts`（纯函数，可独立测试），案件数据位于 `src/data.ts`。
